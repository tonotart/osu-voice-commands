# Voice Commands for osu!
`osu! commands for VoiceAttack v2`

This repository is for sharing my osu! voice commands (created in VoiceAttack v2).

**What do you need?**

[VoiceAttack v2](https://store.steampowered.com/app/3046550/VoiceAttack_v2/) and [osu!](https://osu.ppy.sh/home/download)

**What is VoiceAttack v2?**

VoiceAttack v2 is a program that lets you control your PC with your voice; it costs about €12 on Steam.

**So, what is this repository?**

Basically, this repository includes 26 osu! commands/hotkeys; they all start with “jarvis” (so the word isn't accidentally detected), but feel free to change that.

By the way, I designed this for osu!stable, so some commands might not work in osu!lazer.
